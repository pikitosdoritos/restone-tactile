# ReStone Tactile

Сайт-прототип студентського проєкту ReStone Tactile (команда Sludge2Product, Youthquake 2026): бетонна тактильна плитка 300×300×60 мм для безбар'єрних міст.

- `index.html` — головна сторінка
- `form.html` — запит на зразок або відгук
- `styles.css`, `app.js` — стилі й логіка (без фреймворків)
- `config.js` — посилання на приймач заявок (`FORM_ENDPOINT`)
- `img/` — візуалізація плитки, превʼю для соцмереж, іконка

Статичний сайт: публікується на GitHub Pages без збирання.
